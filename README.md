# Hacktrek-WebCrawler

Advanced Reconnaissance Framework Dashboard

## Features

- Header Scanner
- Form Extractor
- Tech Detection
- robots.txt Analyzer
- Sitemap Fetcher
- Subdomain Discovery
- URL Parameter Extraction

## Tech Stack

- React
- FastAPI
- Python
- CSS3

## Run Frontend

npm install
npm run dev

## Run Backend

uvicorn api.server:app --reload
